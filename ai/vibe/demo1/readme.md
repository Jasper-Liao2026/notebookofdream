# 轻松上手Vibe Coding

想去用ai写代码，但ai生成的要不是“幻觉代码”，看起来像那么一回事，一跑就出错，要么是屎山代码，能跑，但乱的想改都不知道哪里下手

这个指南，不是怎么写代码，而是让我们去与ai协作写出靠谱代码

- 新手 自然语言编程
- 不要急于写代码，先思考，规划md文件
    每次prompt 都会自动带上规划，保持一致性，有整体的约束

## 操作的核心方法
- 第一步：规划就是一切
不要让ai去写代码，先强制他去读懂你的技术栈和项目规划(/init)
就好像你不会让新来的员工直接干活，去阿里入职 会得到阿里java手册
得让他熟悉公司业务流程一样，AI 生成代码逻辑清晰多了
新手把codex，cc 工具，把他们当伙伴，同事，助手

背后逻辑
先划定边界，防止ai擅自多加功能，无限膨胀成屎山
强制模块拆分（好读好维护，ai生成的代码我们都要审核）
引导ai复用独立组件，预先规定数据结构，从根源减少
AI参数、字段幻觉(title,不能是text，字段不能让AI做主)
先生成规划、审核规划、更新规划
这份规划将伴随我们的项目开发完整周期

第二步：胶水编程思维
能抄不写(github经典优质经过验证的代码)，能连不造(a,b,c组件)，指挥ai去找那些已经被验证过千万次的成熟组件，拼乐高一样，把他组装起来
这样产生幻觉和屎山的可能大大降低

我们负责写衔接、调用、流转，联通零件
