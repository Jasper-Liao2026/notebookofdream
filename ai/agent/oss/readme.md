# Agent 的对象存储方案
ai agent 在跑业务的时候，时时刻刻都要读写各种文件
不管是上传的文档，还是ai自己生成的报表、视频图片
普通本地文件夹根本扛不住海量文件的生产环境

## OSS
object storage service 对象存储服务
bucket 是一个对象存储空间，用于存储和管理对象，支持分布式和动态扩容
没有文件夹的概念，所有文件都是以对象的形式存储的
叫对象存储 是因为他不以目录树或磁盘块来管理数据，而是把每个文件当成一个带唯一id和元数据的对象来存取

## 三类场景

- 存放RAG知识库所有源文件，给智能问答提供数据源
- 保存agent自动产出的报表、图表、运行日志
- 统一存放图片、音频、视频，支持多模态ai处理任务

## MinIO
MinIO 是一个开源的对象存储系统，支持分布式和动态扩容
没有文件夹的概念，所有文件都是以对象的形式存储的
每个对象都有一个唯一的id，用于标识和定位对象

直接用阿里云的oss方便，但是要花钱，而且企业内部有的资料也不希望上云
